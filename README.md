# 🏦 Bank Management System using Python and MySQL

## 📌 Project Overview

The **Bank Management System** is a console-based application developed using Python and MySQL. It helps manage basic banking operations such as creating accounts, checking balances, depositing money, withdrawing money, and viewing transaction history.

The project uses Object-Oriented Programming (OOP) concepts in Python and MySQL for storing account and transaction details.

## 🚀 Features

- **Create Account:** Create a new bank account with customer details and an initial deposit.
- **Check Balance:** View the current balance of an account.
- **Deposit Money:** Add money to an existing account.
- **Withdraw Money:** Withdraw money after checking the available balance.
- **Transaction History:** View previous deposits and withdrawals.
- **Input Validation:** Prevent invalid account numbers and negative or zero amounts.
- **Duplicate Account Validation:** Prevent creating accounts with existing account numbers.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Bank-Management-System-Python-MySQL.git
```

### 2. Navigate to the Project Folder

```bash
cd Bank-Management-System-Python-MySQL
```

### 3. Install Required Packages

```bash
pip install mysql-connector-python
```

### 4. Configure MySQL

- Install and start MySQL Server.
- Create a database for the project.
- Configure your database connection details in `database.py`.
- Create the required `accounts` and `transactions` tables.

### 5. Run the Application

```bash
python main.py
```
